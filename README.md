# React Demo — GitOps con ArgoCD

Demo end-to-end de GitOps con ArgoCD sobre kind usando una app React mínima: una aplicación React 18 + Vite empaquetada en una imagen Docker multi-arquitectura (Apple Silicon compatible), desplegada en un cluster Kubernetes local via kind, y gestionada declarativamente por ArgoCD — incluyendo demos de drift detection (escala de réplicas) y version bump visible en el navegador.

Para reproducir el demo desde cero, sigue el [runbook.md](./runbook.md).
